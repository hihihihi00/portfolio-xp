# HIRO XP Portfolio

Windows XP風のポートフォリオ。Vite / React / TypeScript / SCSSで構築しています。

## 起動

Node.js 22.12以上（または20.19以上）が必要です。

```sh
npm install
npm run dev
```

```sh
npm run build    # TypeScriptの型チェックと本番ビルド
npm run preview  # ビルド結果を確認
```

この環境でpnpm-lock.yamlが生成されている場合は `pnpm install`、`pnpm dev` でも起動できます。

## 構成

- `src/App.tsx`: ページ切り替え、ウィンドウ・メニュー状態、ドラッグ操作
- `src/components/`: デスクトップ、ウィンドウ、スタートメニュー、各ページ
- `src/data/portfolio.ts`: ページ名、スキル、デモ制作実績
- `src/styles/desktop.scss`: XP風スタイルとレスポンシブ対応
- `vite.config.ts`: Vite設定

自己紹介は `PageContent.tsx`、実績とスキルは `portfolio.ts` から編集できます。制作実績には提供された2020〜2024年の11案件を掲載しています。Microsoftの公式製品ではありません。

## スマホ対応と起動演出

720px以下では2列のデスクトップアイコン、コンパクトなウェルカムウィンドウ、全画面の詳細ページに切り替わります。メニューは画面外をタップするかEscキーで閉じられます。

初回表示・再読み込み時にXP風の黒い起動画面を2.6秒、「ようこそ」を1秒表示します。「スキップして開く」またはEscキーで即座に開けます。動きを減らす設定では演出を短縮します。起動音はありません。

- `src/components/BootScreen.tsx`: 起動画面と時間の設定
- `src/styles/desktop.scss`: スマホレイアウトと起動アニメーション

## ペイント・電源操作・PCのサイズ変更

- デスクトップまたはスタートメニューの「ペイント」から描画できます。ペン・消しゴム・色・太さ・15回までの元に戻す・白紙に対応します。
- ペイントは他ページへの移動や最小化でも保持され、終了・再起動・再読み込み時にリセットされます。画像保存機能はありません。
- スタート → 終了オプションから「終了する」「再起動」を選べます。終了後は「電源を入れる」で戻れます。サイト内の演出です。
- PC（721px以上）ではウィンドウの四隅をドラッグしてサイズ変更できます。最大化中とスマホではサイズ変更しません。
- 実装: `Paint.tsx` / `PowerDialog.tsx` / `PortfolioWindow.tsx` / `App.tsx`

## ウィンドウとタスクバー

戻るボタンで開いたページの履歴をたどれます。戻り先がない場合は無効になります。同じページを開き直しても履歴を増やしません。履歴はウィンドウを閉じたときや終了・再起動でリセットされます。×で閉じるとウィンドウとタスクバーの項目が消えます。最小化では項目を残し、タスクバーから復元できます。閉じた後はデスクトップのアイコンやスタートメニューから開けます。ペイントを閉じるとその絵もリセットされます。

タイトル・アドレス・タスクの文字は狭い幅で省略表示します。PCのウィンドウは表示領域に収まる位置・サイズに制限されます。

## スキルページ

`src/data/portfolio.ts` の `skillGroups` を編集します。Web Development / Animation & Interaction / Tools の3分類です。元の見出しとタグ一覧のレイアウトを使い、担当領域や説明文は掲載しません。

## アイコン

画面内の絵文字アイコンは、`public/icons/` にある固定SVG画像へ置き換えています。`src/components/Icon.tsx` で共通表示し、ページ名とアイコンは `pageTitles` / `pageIcons` で別管理しています。装飾画像は空のaltとaria-hiddenを指定し、ボタンの名前は文字で読み上げられます。
